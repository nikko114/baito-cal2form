# baito-cal2form
カレンダー方式をフォーム用入力に見せるツール。「なんでバイトのシフト入力がGoogleフォームなん？？？」って思って...

## できること

- カレンダーで、日付ごとにシフト希望（○ / × / 早 / 遅 …）を入れる
- `1日(日) ○` のような1日1行の一覧にして、Googleフォームに書き写しやすくする
- 書き写した行に ✓ をつけられるので、フォームと行き来しても迷わない
- 曜日パターン（毎週◯曜は× など）でまとめて埋める、出勤できる日数を数える、備考欄の下書き
- シフトが決まったら確定シフトを入れて、時給・交通費・深夜割増などから給料の見込みを出す（月ごと・年の合計）

データはその端末のブラウザの中にだけ保存する（サーバーには送らない）。

## 使う

https://nikko114.github.io/baito-cal2form/

iPhone では Safari で開いて、共有ボタン →「ホーム画面に追加」して使う（Safari のままだと、しばらく開かないうちにデータが消えることがある）。

## 開発

- ビルドなし。素の HTML / CSS / JavaScript（ES Modules）
- ローカルで見る: `python3 -m http.server 8000` → http://localhost:8000
  （ES Modules はファイルを直接開くと動かないので、簡単なサーバー経由で開く）
- テスト: `npm test`（Node.js 20 以降。依存パッケージなし）
- 計画書: [docs/PLAN.md](docs/PLAN.md)
